# chibi muere

A one-page static portfolio site for GitHub Pages.

## Files

- `index.html` is the site entry point.
- `styles.css` contains the responsive styles.
- `404.html` provides a custom not-found page.
- `favicon.svg` provides the browser tab icon.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing these files and the `/ (root)` folder.
5. Select **Save**, then wait for GitHub to publish the site.

The site does not require a build command, package manager, or server. Keep `index.html` at the repository root so GitHub Pages can use it as the entry point.
